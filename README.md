# 🌐 Noosphere

> **Noosphere** —— 着手构建一份终身积累的个人知识库

## 📖 主题

Noosphere 源自希腊语 *nous*（心智）与 *sphaira*（球/圈），意为「思想之圈」，指由人类知识与思想交织而成的星球尺度心智空间。本项目以此命名，寓意：

> 将散落在脑海与碎片文档中的知识，汇聚成一个持续生长、相互连接的个人知识圈。

## 🎯 作用

本项目是一个基于 [Obsidian](https://obsidian.md/) 的个人知识库（Vault），采用 **PARA 方法** 组织信息，用于：

- 📥 **收集** —— 快速捕获灵感、想法与临时笔记，不被分类所打断
- 🗂️ **管理** —— 通过清晰的项目（Projects）与领域（Areas）结构，让知识有章可循
- 🔗 **连接** —— 利用 Obsidian 双向链接与图谱视图，发现知识间的隐藏联系
- 💡 **沉淀** —— 将碎片笔记整理为可复用的知识资产，支撑学习、写作与创作

## 🌱 愿景

1. **终身积累**：打造一个可持续使用多年、不会过期的个人知识库
2. **即取即用**：任何知识在需要时都能被快速找到、理解并运用
3. **自由生长**：遵循「最小必要结构」原则，随使用不断演化，而非一开始过度设计
4. **AI 增强**：借助 AI 协作工具（Cline / Claude）辅助整理、检索与创作，让知识管理更高效

## 📂 目录组织（PARA 方法）

本仓库采用 [PARA 方法](https://fortelabs.com/blog/para/)（Projects / Areas / Resources / Archive）组织内容：

| 目录              | 名称     | 作用                | 典型内容           |
| --------------- | ------ | ----------------- | -------------- |
| `00_Inbox/`     | 📥 收件箱 | 快速捕获一切想记录的内容，定期清空 | 灵感、临时笔记、待整理的剪藏 |
| `01_Projects/`  | 🚀 项目  | 有明确目标和截止时间的任务     | 正在写的文章、进行中的项目  |
| `02_Areas/`     | 🗺️ 领域 | 需要长期维护的责任范围       | 健康、财务、职业、某门课程  |
| `03_Resources/` | 📚 资源  | 感兴趣的主题与参考资料       | 主题笔记、书籍、文章、资料  |
| `99_Archive/`   | 🗄️ 归档 | 不再活跃但需要保留的内容      | 已结束项目的笔记、过期资料  |

### 使用流程

```
📥 捕获（00_Inbox）→ 🗂️ 归类（01_Projects / 02_Areas / 03_Resources）→ 🗄️ 归档（99_Archive）
```

1. **捕获**：任何想法先放进 `00_Inbox/`，不做分类，避免打断心流
2. **归类**：定期（如每周）整理收件箱，将内容移动到合适的目录
3. **连接**：使用 `[[双向链接]]` 建立笔记间的关联，构建知识网络
4. **归档**：项目结束或内容不再活跃，移入 `99_Archive/` 保持主目录整洁
